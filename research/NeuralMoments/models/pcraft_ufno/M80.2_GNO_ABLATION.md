## Why this module was added

M80.1 combines a P-CRAFT global spectral context map with exact M72 native interval descriptors. Before M80.2, interval descriptors were fused independently and reduced by a mass-weighted global pooling operation. There was no explicit local interaction between neighboring native intervals.

M80.2 adds an optional Geometry Neural Operator (GNO)-style local integral branch. It is an adaptation of the neural-operator integral-kernel idea, not a wholesale import or claim of exact upstream GINO/NeuralOperator reproduction.

## Local graph definition

For native interval centers \(x_i\), build a self-inclusive k-nearest-neighbor graph:

\[
\mathcal N_i=\{i\}\cup\operatorname{kNN}_{K-1}(x_i).
\]

The graph is geometry-only, stored as int32, and cached per geometry hash, neighbor count and device. It is not a dense \(N\times N\) adjacency matrix.

For edge \(i\leftarrow j\), the seven-dimensional edge descriptor contains:
- normalized relative center coordinate \((x_j-x_i)/L\);
- log interval-extent ratio \(\log(e_j/e_i)\);
- log mass ratio \(\log(m_j/m_i)\).

The local kernel is positive:

\[
\kappa_{ij}=\operatorname{softplus}(\operatorname{MLP}(e_{ij})).
\]

It is combined with native interval mass weights and normalized over the local neighborhood:

\[
\alpha_{ij}=
\frac{\kappa_{ij}m_j}
{\sum_{k\in\mathcal N_i}\kappa_{ik}m_k}.
\]

The local integral message and residual update are:

\[
g_i=\sum_{j\in\mathcal N_i}\alpha_{ij}W_vh_j,\qquad
h_i'=h_i+\operatorname{MLP}_{\rm upd}([h_i,g_i]).
\]

The updated interval features are then reduced using the existing global mass-weighted pooling and M72 bounded odd moment response head.

## Important scope

- P-CRAFT remains the global spectral backbone.
- Every M72 native interval is retained.
- GNO operates on native interval centers, not on a downsampled substitute.
- GNO is optional and is disabled in the existing \`large\`, \`xl\` and \`xxl\` presets.
- \`large_gno\` and \`xl_gno\` are explicit ablation presets.
- Transolver++ is not enabled by default. Previous M8 results showed negligible accuracy gain with substantially higher cost; it must earn inclusion in a new matched experiment.
- DensiCrafter remains an offline design teacher; TRELLIS remains a geometry source. Neither is silently mixed into the M72 formal corpus.

This does not certify GNO or XL. Run paired \`large\`/ \`large_gno\` preflights at the same chunk size, then paired \`xl\`/\`xl_gno\` preflights. Record graph build time, cache hits, allocated/reserved memory and step time.

Preflight establishes resource/graph viability only. GNO promotion requires a same-data, same-seed, same-step 200–500 step pilot and improved held-out Jacobian tail or downstream solver results without unacceptable wall-time cost.
