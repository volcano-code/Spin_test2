# M36　小切块求积与 PINO 对照

三种子沿用解析训练的 6³ Logistic-atom Spin-PINO、数据划分、120 步预算和原验证集选步。选中的步数为 20、20、60。评估冻结参数，真实查询进训练的数量为零。三组输入包括 Noodles 原有三个查询、八个新盒形设计域各自的半椭球切割，以及新留出的一件 Bunny 网格上的三个切割。Bunny 的精确答案由 W1 和 W3 独立产生，所有方法均按登记顺序评估。

## 方法

- 在四组笛卡尔对照中交叉改变每轴节点数（6 或 24）和温度（0.12 或 0.0075）。24³ 个子节点继承其 6³ 父节点的冻结学习权重，节点处的密度从同一份 8³ 设计域输入三线性采样。预先指定 24³、温度 0.0075 为主比较组。
- 对严格包含在输入立方体内的有界椭球，增加局部求积。用原生系数构造仿射变换，将单位球的 768 个体节点和 128 个面节点送到切块。十矩采用体积分，导数采用界面的面积分。此导数逼近所表示连续密度的形状导数，未把跨越体素边界时的固定体节点离散和当作可微真值。不满足椭球范围条件时调用预定的 24³ 低温对照。
- 对每组规则再运行单位权重的数值积分。两路共享几何、节点、温度及导数公式。网络只控制原来的 216 个正权重。计算精度为 double 的新积分器在粗网格上复现既有结果；密度采样仍采用原来的 float32 格式。
- 解析留出组中，每个小椭球的中心位于盒子的正 x 面，其他五个面与之分离。用单位半球表面积分和半球体积积分的闭式公式生成原生系数、十矩和全部 100 个导数标签。

## 同一预算下的精度

下表先对每个查询计算十矩相对 L2 和 Jacobian 相对 Frobenius，再对查询等权平均。学习组另取三个训练种子的均值。两种方法的真实训练查询预算均为零；24³ 节点数是 6³ 的 64 倍。

| 查询组 | 原 PINO 6³ 高温 | PINO 24³ 低温 | PINO 局部求积及回退 | 单位权重局部求积及回退 |
|---|---:|---:|---:|---:|
| 八个新解析盒，r / J | 62.719 / 0.490 | 1.716 / 0.359 | 0.454 / 0.449 | 0.481 / 0.476 |
| Bunny，三个新查询，r / J | 45.685 / 0.632 | 1.159 / 0.358 | 0.393 / 0.359 | 0.079 / 0.091 |

Bunny 的最小切割使用局部球坐标规则，另两个椭球超过固定网格的定义域，按协议回退。上表后三列对应的网络几何特征完全相同。该模型上，纯数值对照比学习组的局部及回退结果更准确；解析组出现幅度较小的相反排序。三个相关查询不能用于估计模型间变异。

| Noodles 查询 | 原 PINO r / J | 只加密 r / J | 只降温 r / J | 同时加密降温 r / J |
|---|---:|---:|---:|---:|
| 小椭球起点 | 70.198 / 0.599 | 62.760 / 0.636 | 0.880 / 0.980 | 0.617 / 0.768 |
| 第二次更新后的小椭球 | 79.203 / 0.624 | 71.029 / 0.658 | 0.543 / 0.790 | 1.801 / 0.640 |
| 原双曲面起点 | 0.469 / 0.743 | 0.548 / 0.767 | 0.662 / 1.476 | 0.668 / 0.721 |

第一个小椭球的真质量约 0.000736。PINO 在粗网格高温下平均预测 0.07027，细网格低温下为 0.00127。第二个椭球上，单独降温的十矩误差比同时加密更低。因所有 sigmoid 门控至多为 1，同一规则单位权重的质量构成学习预测的上界。8³ 几何下局部求积给出的前两个椭球质量上界分别为真值的 15.05%、15.42%，此时仅调整学习权重无法恢复真实质量。

## 几何分辨率补充实验

固定单位权重、求积和温度，只替换输入占据点。同一条局部求积规则对 Noodles 小椭球起点的 r / J 误差随几何分辨率变化为 8³ 的 0.849 / 0.830、16³ 的 0.397 / 0.526、32³ 的 0.306 / 0.185。第二个小椭球在 32³ 下为 0.296 / 0.180。Bunny 最小切割分别为 0.081 / 0.055、0.789 / 0.781、0.117 / 0.096。点采样相对于切割界面的位置会变化，单个模型上的误差未呈单调关系。这项诊断未计入采样占据网格的时间。

## 复现

从 W6 仓库根目录运行以下命令。主结果及每个种子的逐例数值保存在本目录的 M36_REFINEMENT.json。若追加原生候选诊断，可传入含 q 字段的 JSON 路径和输出文件路径，使用 --query 与 --anchor。坐标适配器返回源坐标系原生系数的原始十矩 Jacobian。

```bash
p=research/NeuralMoments/models/pcraft_ufno/spin_pino
pkg=research.NeuralMoments.models.pcraft_ufno.spin_pino
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -m "$pkg.refinement_ablation" \
  --extra "$p/M36_BUNNY_INPUT.json" --output m36-replay.json
python -m pytest -q "$p/tests/test_refined_quadrature.py"
```

该轮比较固定解析训练与未参与训练的真实几何。最终采用哪种代理仍需与单位权重数值积分进行端到端同精度比较，以及精确几何复核。
