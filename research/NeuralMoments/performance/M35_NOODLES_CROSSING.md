# M35 · Noodles 正则材料与独立十矩

实验沿用 M34 的固定件 F′ 和可变材料 D′。W2 提供精确有理多面体布尔输出、实际刀具、逐面来源和对应 SHA-256。W1 对保留的体积重新求积并检验几何集合。模型坐标原点、单位均匀密度，十矩顺序为质量、x、y、z、xx、yy、zz、yz、xz、xy。所有数值描述针对有限三角化的切削体。

## 为什么能识别真实交集

1. M26 用精确有理谓词检查输出的自交和邻接。按连通分量检查法向外侧的确切绕数。设计域复用 M34 已核验并绑定 SHA 的嵌入边界。
2. 对星形刀具，用同一个严格可见核点向 320 张外表面作有向四面体。逐设计父面裁剪、投影和求和，再与已保存子三角的精确投影面积比较。逐张验证裁剪子面的平面、覆盖范围、正向和面积。闭合性和完整设计边界补片限定了刀具载体上的补片。有部分覆盖的父面固定了连通刀具载体上的整数常差。
3. 通用验证器枚举源三角相交候选，使用有理坐标求交段、方向和端点，并与保存网格上每一条跨来源有向边一一比对。对全部子面验证母面和符号。完整接缝相等使真实覆盖与观测覆盖之差在源连通分量上为常数。部分覆盖的父面将该常数定为零；未切到的分量以单个精确绕数确定常数。非横截或点触输入需要独立的事件处理，本检验会中止。
4. 对椭球扰动，逐模型记录不同父面组合所确定的顶点、接缝和有向三角剖分，消除输出编号变化。严格的源特征符号只证明该有限多面体状态存在局部横截邻域。离散样本不提供整个扰动区间无事件的半径。
5. M25 独立积分器对有向原点四面体精确求得十个有理数。另一个四面体公式实现给出向外取整的区间，每个分量宽度至多为面数除以 (120·2^{112})。整件 F′ 与保留体的并集另行计算，独立核对三者边界有向链及全部十个积分。整件网格收据仅证明已列出的边界链、十矩和固定尖端；终局残差、制造适用性、PINO 加速和整件独立自交检查仍有各自的验收条件。

## 重放

使用 M25 的 GMP 四面体积分器与 M26 的 GMP 嵌入检查器。Python 依赖 NumPy，使用 gmpy2 可显著改善大分子分母的重放时间。`sample` 目录须含 W2 原始 `result.json`、`cutter.txt` 和 `receipt.json`。

```bash
python m35_noodles_crossing.py sample Dprime.txt evidence --ten BIN_M25 --embedding BIN_M26 --full
python m35_general_seams.py sample Dprime.txt BIN_M26
python m35_bounded_ten.py sample/result.json
python m35_assembled.py Fprime.json Fprime.ten sample/result.json evidence/sample.ten evidence/sample.w1.json assembled.json
python -m unittest -q test_m35_noodles_crossing test_m29_heart_cut_faces test_m30_heart_cutter_faces test_m34_noodles_partition
```

通用区域验证器接受 intersection 和 difference。星形验证器接受 intersection。原生默认种子的非星形多分量刀具使用通用验证器。W3 负责同源导数及差分检验。W0 负责外层原生求解器判定。

## 十个系数的补充实验与默认种子整件

W2 先用包围盒裁剪 D′ 并映射回原始父面。在基点和十个系数各自正负两个步长处，W1 对全部 41 个输出重算有理十矩。每个分量都落在第二套积分实现给出的 112 位向外舍入区间内。全部 41 组原始父面顶点标识、接缝、有向三角剖分一致。每个刀具均在原始、未裁剪的 D′ 上通过严格特征位置检查。先前 13 个直接全域布尔样本还与对应裁剪样本逐面重合。其余 28 个样本采用 W2 裁剪区域构造，W1 核查十矩与接触特征。下列命令重算单个样本。

```bash
python m35_cropped_stencil.py sample Dprime.txt evidence BIN_M25 > sample.supplement.json
```

默认种子第 3 次调用与 F′ 的整体并集为 61,796 点、124,352 面，模型坐标质量约 0.7952362492363927。6,172 张未能按三角形直接抵消的差异面在各自支撑平面上精确抵消。全部十矩的独立区间包含对应精确部件矩之和，最低点为唯一的预定尖端。此例的切削体通过通用多分量载体检验，单独提供的区域收据与十矩收据必须绑定同一组操作数及输出。

