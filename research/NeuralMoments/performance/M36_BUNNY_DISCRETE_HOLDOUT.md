# M36 · 三个 Bunny 曲面切割的独立标签

目标是检验只用解析数据训练过的 PINO 能否在第二个三维网格上预测离散切割十矩及其导数。文件 `data/bunny.off` 是项目内的闭合 Bunny 网格。这里只评价几何查询，未在 Bunny 上指定旋转轴、陀尖或固定壳层。

网格有 3,485 个顶点，6,966 个三角面，20,898 条有向边均有唯一逆向边。几何以原始包围盒中心平移，再将最大边长等比缩放到 1.8。查询坐标系与该归一化模型一致，单位密度。独立 GMP 检查覆盖 45,335 对候选三角面，验证了嵌入性和正确朝向。没有对网格修补或重采样。

探针对应的中心和大小只使用未切割的网格确定。前两项位于最大面积三角面的中心，第三项位于中心 x 坐标最小的面。三个椭球的主尺度分别为 (0.11,0.079,0.054)、(0.32,0.25,0.20)、(0.58,0.44,0.31)。所有探针使用相同比例的固定剪切，并用 Spin-It Faster 的 162 顶点逆 Gauss 离散源。每个查询由精确有理数 libigl/CGAL 布尔交产生材料，在输出三角形上积分质量矩及法向速度。W1 独立恢复输入曲面的交线、来源面与保留区域，检查切割体和输出表面的嵌入性。

| 切割 | 保留体积与质量 | 输出三角面 | 交线段 | 导数差分最大缩放误差 |
|---|---:|---:|---:|---:|
| 最大面积面，小椭球 | 0.000938252 | 298 | 70 | 2.686e-8 |
| 最大面积面，中椭球 | 0.026766586 | 698 | 168 | 8.636e-11 |
| 最左面，大椭球 | 0.120311838 | 1,160 | 271 | 4.498e-10 |

每一个基点的全部 10 个原生系数都用两个步长（2⁻¹⁹、2⁻²⁰）进行独立中心差分，共计 120 次扰动布尔、600 个标量验证。缩放分母为 max(1, |Jᵢⱼ|)。对第三个切割的 c₀ 负向粗步长，面内的三角剖分发生变化，原始来源面的连接和交线保持一致。其余扰动的有向三角剖分也相同。每个样本都在结果中单独列出。

W6 收到的是 `evidence/m36-bunny/heldout.json`，包含 8³ 占据采样及 3 组系数、十矩和 10×10 Jacobian。扩展全列差分时重新运行了三个基点，两次结果中的每个参数、十矩及导数数值完全一致。原始网格 JSON 中有 4 个三角形的循环起始顶点发生改变，保持有向三角形不变。首次及重放的原始哈希、消除循环顺序影响的哈希都记录在 `audit.json`。单独的 `m36_occupancy.py` 使用精确扫描线重算 16³ 和 32³ 采样，并确认 Noodles 8³ 与 W0 M35 逐点一致。

## 重放

下列参数中的可执行程序分别来自 W2 M35 离散逆 Gauss 源、W2 M34 有理输入 CGAL 后端及 W1 M26 精确嵌入性检查。W3 的 `crossing_flux.py` 所在目录来自提交 `618e194b6c53b3860afe239ef87b215e95c094ce`。推荐安装 gmpy2 加速精确算术。

```bash
python research/NeuralMoments/performance/m36_bunny_holdout.py \
  --off data/bunny.off --out /tmp/bunny-m36-fresh --workers 4 \
  --source "$M35_ELLIPSOID_SOURCE" --boolean "$M34_EXACT_BOOLEAN" \
  --embedding "$M26_EXACT_EMBEDDING" --w3 "$W3_Noodles_M32"
python -m pytest -q research/NeuralMoments/performance/test_m36_bunny_holdout.py
```

Bunny 的三个样本属于同一个几何，且前两项共用一个切割位置。这个集合提供跨几何的查询级验证，不能单独给出旋转设计或跨类别准确率。
