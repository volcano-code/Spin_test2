# M41 · 高分辨率几何和 Newton 所需的十矩导数

目标是在单卡 5090 的预算内，用粗尺度 P-CRAFT/UFNO 编码整个物体，按查询对细几何积分。这里公开本轮可重放的 CPU 数值实验。分支提供实验模块，没有改写生产求解器。七个雅可比参考均来自同一个 Noodles 设计域；训练实验另用十个不同查询。完整 GPU 主干训练、其他物体和达到相同收敛条件的端到端用时仍待验证。

## 结果

| 三轴原生面通量 | 七个状态的完整雅可比相对误差，中位 / 最大 | 七个状态的轴向惯量梯度相对误差，中位 / 最大 |
|---|---:|---:|
| 每个轴向 256² 条射线 | 0.1015% / 0.1597% | 0.1349% / 0.2017% |
| 每个轴向 512² 条射线 | 0.0485% / 0.0628% | 0.0632% / 0.0876% |

前两项参考是 M38 的两个已接受状态。另五项是 M37 的三个椭球交集和两个双曲面差集。所有参考量均为已有的原生移动面雅可比，逐状态比较 10×10 矩阵的 Frobenius 相对误差。惯量梯度使用矩阵中 xx 和 yy 两行之和。射线数量描述横向积分密度，未分配同边长的稠密三维神经特征。

- **几何表示的影响。** 在 M38 两个状态上，从光滑二次曲面求简单根并解析积分，以每个轴向 512² 条射线计算，沿两状态之间球面轨迹切向的十矩导数相对原生参考分别差 59.41%、48.19%。同样的三轴射线密度，使用原生有限三角面后，这两个误差分别为 0.00873%、0.02797%。这两个数字属于指定方向。光滑表示与有限面片教师定义了不同的积分域。这项对照也改变了界面求积公式，不能解释为一项单因素神经消融。
- **微小步长。** 在 M38 两个状态各取轨迹切向、常数项和 xy 交叉项投影后的切向，共六个观测。固定半步角 10⁻⁶ 与 1024³ 中心网格，硬体素中心差分的十矩 Jv 相对误差中位数为 3.267%，最大 13.481%。同一组横向采样线保留连续的 x 切割端点后，中位数为 0.127%，最大 0.356%。单轴解析端点在 M37 的一个椭球上仍有 3.34% 的完整矩阵误差。完整矩阵对照采用三轴面通量。
- **学习权重。** 在五个 Noodles 原生优化候选上训练八个正的子体素分相权重，在另五个历史查询上测试。与同节点均匀权重比较，64³ 下的十矩中位相对误差从 0.592% 降到 0.378%。128³ 从 0.100% 升到 0.154%，256³ 从 0.0351% 升到 0.0359%。每个分辨率单独拟合。分块反传的参数梯度与整批复步微分相对差低于 9.2×10⁻¹³。这项学习对照没有训练 UFNO。
- **拓扑。** Noodles 原始可设计域 D′ 有一个连通的闭合边界。1024³ 的离散材料按六邻域得到 63 个分量，最大分量外仅有 163 个体素。2048³ 为 125 个分量，最大分量外共有 362 个体素。按所登记的离散复形，欧拉特征分别为 −239、−221；嵌入闭合源实体参考为 −198。此处考察切割前的 D′。独立薄球壳测试的 27 个格点偏移中，厚 1.2288 个单元时全部材料六连通，同时全部出现背景二十六邻域的内外通路。

## 计算

先从三角网格生成 x/y/z 三套材料区间并缓存，按相同采样位置比较不同的切割候选。光滑二次曲面路线对每条直线上的正值区间积出十个单项式；对简单内根求解析导数。代码返回近切点、端点接触、缺少正则交点等诊断，横向求积仍有离散误差。

三轴面通量用原生三角面的顶点和每个顶点对十个参数的速度。以单位外法向 n 的投影系数 n_x²、n_y²、n_z² 分摊三个方向的积分，三者之和为 1。每个方向把投影面积换回面面积后，离散权重正比于 |n_axis|。积分只包含设计域内的移动切割面；对差集翻转符号。该路径需要原生切割器及其顶点导数；参考十矩雅可比只在计分时使用。所测双曲面截断盖均未进入布尔输出。高阶拓扑切换、接触与未知类型仍应回到原求解器。

## 重放

从本目录执行。Python、NumPy、SciPy 可运行解析测试和保存特征的训练；基于 VTK 的脚本使用 VTK 9.3.1。解开同目录的 replay-data.zip 后，完整逐例结果、原生切割包和学习特征会放回相应的子目录。将 KIT 设为此前 Spin_5090_HighRes_Kit 的解压目录，含 inputs/Dprime.txt、native/exact/report.json 和 geometry/。部分脚本可直接读取原始 M37/M38 实验的同名文件。

```bash
unzip -o replay-data.zip
export KIT=/absolute/path/to/Spin_5090_HighRes_Kit
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
(cd intervals && python -m unittest -v)
python intervals/compare.py --kit "$KIT" --output smooth-local.json
python intervals/native_flux.py --kit "$KIT" --anchor-source derivatives/fixtures/online/anchor/source.json --output flux-local.json
python intervals/native_panel.py --design "$KIT/inputs/Dprime.txt" --runs derivatives/fixtures/runs --output panel-local.json
python training/phase_readout.py --features training/features.npz --output fit-local.json
```
