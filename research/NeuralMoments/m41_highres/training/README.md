# Noodles 子体素求积权重的同节点对照

对 Noodles 同一个设计域 D′，把每个已占据体素按 (x,y,z) 网格索引的奇偶性划入八类。数值对照给每类乘 1。学习组在同一份体素和相同十个矩的积分基函数上乘八个共享的正权重，每种分辨率单独拟合，权重和固定为 8。每个参与体素的小立方体都积分到二阶矩，包括 h²/12 修正。这里是坐标奇偶分相的浅层校准器，与 M39 主干的八个空间分区及权重彼此独立。

训练和评测均使用 M38 已归档的原生三角切割。训练用 exact 轨迹中的 call-002 至 call-006，五次均为交集。评测使用历史 panel 的 p1 至 p5，其中两次交集、三次差集。训练与评测共 10 个不同的归一化 q，最近跨组欧氏距离为 0.055439。评测点仍来自同一物体，沿同一条大圆路径；这个实验衡量已知物体上的查询迁移。相同超参数用于所有分辨率，未按评测结果选超参。每个样本均核对原生网格、切割器和结果文件 SHA-256，并把模型空间的质量矩转换至 tip 空间与轨迹记录相互验证。

| 细几何 | 评测十矩中位相对 L2，均匀 / 学习 | 评测最大 Izz 保留率误差，百分点，均匀 / 学习 |
|---|---|---|
| 32³ | 2.70576% / 1.57751% | 1.16362 / 0.98210 |
| 64³ | 0.59215% / 0.37751% | 0.23680 / 0.17461 |
| 128³ | 0.10023% / 0.15352% | 0.04296 / 0.06717 |
| 256³ | 0.03508% / 0.03593% | 0.01044 / 0.01053 |

十矩误差计算对象为模型坐标下保留下来的可变区域。轴向惯量加回固定几何，并除以原模型 Izz。两种方法对五个评测查询均给出与原生 90% 门槛相同的决策。32³ 时，两种方法在训练集上各有一次门槛错误。256³ 的 call-005 与 call-006 使用均匀权重所得体积，与上一轮独立 x 区间积分相同，Izz 之差均小于 5×10⁻¹⁶。

对每个训练查询，将体素分成八个互不重叠的 z 薄片。先对薄片的十矩求和，计算损失对总矩的导数，再遍历薄片计算权重梯度。取一组非零 logits，将分块解析梯度与整批目标函数各参数的独立复步微分对比，四种分辨率的相对 L2 差异均低于 9.2×10⁻¹³。该检查覆盖局部求积权重，原生 UFNO 完整反向传播仍由上一轮 PyTorch 探针验证。

拟合使用 BFGS、相对十矩平方误差、以训练时单位权重的平均相对平方误差归一化、固定 0.1 的权重偏离正则化，见 fit()。个别粗网格训练权重接近零。这个试验没有拟合主干、验证几何导数、测量 GPU 时间或显存。八类权重分别训练，无法把四行数字解释成一个冻结权重模型的跨分辨率表现。

使用 NumPy 和 SciPy 可直接复现已有特征上的全部训练、梯度检查、评测及单查询误差。请先进入本目录。

```bash
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 python phase_readout.py --features features.npz --output replay.json
```

从原生三角几何重新提取特征还需 VTK 9.3.1、M38 完整归档的 inputs、online/exact、panel 目录和上一轮单卡工具包的 geometry 目录。

```bash
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 VTK_SMP_MAX_THREADS=1 python phase_readout.py \
  --handoff /path/to/M38 --geometry-code /path/to/Spin_5090_HighRes_Kit/geometry \
  --features rebuilt.npz --output rebuilt.json
```

features.npz 包含各几何分辨率形状为 (10,8,8,10) 的可加矩张量，轴依次为查询、z 薄片、体素相位和原始矩分量，另含精确参考、原始参数和源数据指纹。results.json 提供逐样本误差、权重、优化迭代数和梯度验证数据。
