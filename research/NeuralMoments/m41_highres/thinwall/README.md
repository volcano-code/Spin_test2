# 薄壁与拓扑复核

两项 CPU 实验都采用体素中心判定。运行 `shell_check.py` 需要 NumPy、SciPy。运行 `noodles_topology.py` 另需 VTK 9.3.1 与解压后的上一轮 Spin_5090_HighRes_Kit。

```bash
python shell_check.py --output shell_check_local.json
OPENBLAS_NUM_THREADS=1 VTK_SMP_MAX_THREADS=1 python noodles_topology.py --kit /path/to/Spin_5090_HighRes_Kit --output noodles_topology_local.json
```

## 真实设计域

源网格 D′ 是切割前允许挖空的区域，面片方向一致，边均被两个面片共享，每个顶点的 link 为单环。脚本从三角网格计算边界欧拉特征。把该源曲面解释为嵌入且封闭的三维实体边界时，实体欧拉特征是边界欧拉特征的一半。脚本没有单独重做三角形自交判定。该项验收不包括最终成品与固定外壳。

离散复形将每个占据体素中心视为顶点。如果一条单位轴向边、一个单位方格或单位立方体的全部顶点被占据，就将其加入。对应的材料连通性取六邻域。对 x 行区间计数，按相邻行和四行交集作容斥，可在不展开稠密立方体的情况下得到该复形的欧拉特征。30 个独立生成的小型三维体素数组以稠密直接计数及 SciPy 连通域作为程序对照。

## 有解析解的薄球壳

100 mm 边长的域内放置外半径 3.91 mm 的薄球壳，检查四种厚度、三个分辨率与 27 个确定的格点偏移，球的法向遍及三维各方向。准确体积取内外球体积之差，准确轴向惯量取同轴均匀实心球惯量之差。计算记录实体六连通及内腔可否沿背景六邻域、二十六邻域通到外部。材料六连通、背景二十六连通为本文选择的数字拓扑准则。部分偏移在立方网格下对称等价，表中次数不用于估计独立失败概率；观测到的通过厚度不代表任意几何的安全阈值。
