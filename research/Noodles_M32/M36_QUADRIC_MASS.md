# M36 · Noodles 固定轴惯量约束下的最小质量

在 M32 的相同原轴、陀尖、外形、固定材料 F′ 和单密度条件下，得到一个降低质心、四项平衡矩精确为零的构造。它由一个切去 D′ 部分材料的内接锥台和八个微小长方体修正组成，**减重 26.510709%，保留 90.016358% 的原固定轴惯量**。质量与材料体积同比例变化。另一个单锥面候选在几何容差下通过独立包围验证。

| 几何和验收 | 整模减重 | 惯量保留 | 质心高度变化（模型单位） |
|---|---:|---:|---:|
| 连续斜圆柱，在 D′ 中切除 | 26.52341–26.52716% | 90.00856–90.01144% | +0.001036 至 +0.001148 |
| 圆柱内接多面体，加八盒精确平衡 | 26.523483% | 90.011354% | +0.0011014 |
| 连续斜圆锥，在 D′ 中切除 | 26.51064–26.51439% | 90.01356–90.01644% | −0.000266 至 −0.000154 |
| 锥面内接多面体，加八盒精确平衡 | 26.510709% | 90.016358% | −0.00020005 |

原始高度为 0.90272439。为了处理圆柱解质心上升的问题，第二次设计加入质心不升要求，搜索目标比原质心低 0.0002。锥面候选本身的横向质心 L1 偏移上界为 0.000083 模型单位，最大惯性轴与原轴夹角的正弦不超过 0.000170。连续候选的四个矩只有区间证明。两种盒修正构造分别严格抵消横向一阶矩和 xz、yz 矩，质心和主惯性轴均对准指定轴。八个修正盒非常薄，其几何尺度和打印可制造性必须另行考查。结果只涉及同一件真实 Noodles 工程几何。完整区间和修正体积见 [数值收据](M36_QUADRIC_MASS.json)。

## 几何与优化

在登记的模型坐标中取 d=z−0.9，除去 D′ 内满足下式的材料。

```
(x−tx−sx*d)² + (y−ty−sy*d)² ≤ (R+k*d)²
```

圆柱使用 k=0，锥面使用线性半径。整个设计域位于 z∈(0,2) 内，半径在该区间始终为正。数据中的 R、tx、ty、sx、sy、k 是精确十进制有理数。先以多边形近似截面，分别用圆柱的竖直通量和圆锥顶点的带符号四面体积分求十矩，再通过数值求根和 32–512 边细化求候选。独立验收阶段不使用这些浮点预测值。

每个候选均以两套精确有理 256 边截面夹住连续圆。验证所有顶点位于内圆内，以及外多边形每条边与圆心的有理距离大于半径。截面的仿射平移和正缩放保证此包含关系对整个 z 区间成立。在原 D′ 上分别执行四次 libigl/CGAL 精确交，使用 W1 带符号四面体积分和 112 位向外取整核计十矩。两组夹层体积分别低于 0.000054 和 0.000054。计算惯性轴角时，直接界定夹层上的 x(z−H)、y(z−H)，保留其一阶与混合矩的相关性，其中 H 是保留体的质心高度。

修正盒来自 W1 已证实位于 D′ 内的格点单元，在水平面成四对反号布置，中心 z 对内相同。每个盒子 xy 宽为 7/256，z 高等于其体积除以宽度平方。先检查整单元与连续二次曲面分离，再对四对盒子的体积差解精确四阶线性系统。若 d 表示解出的带符号体积差，左右两盒体积分别取 1e−7+max(d,0)、1e−7+max(−d,0)。两者严格位于各自容量内部。保存的四个 CGAL 求交网格包含大空腔，不含这八个符号高度的小盒，实际盒高可由内接网格的精确十矩重建。材料连通性、整件嵌入、自交和制造验收各自需要几何证据。

## 去除量的全域上界

设 S 为 D′ 的任意可去除部分，B=0.1 Izz(A)，a(z)=tx+sx*(z−0.9)，b(z)=ty+sy*(z−0.9)。取 λ=1/R² 以及圆柱 q=1−λ((x−a(z))²+(y−b(z))²)。有

```
vol(S) = ∫S q + λ∫S(x²+y²) − 2λ∫S(a(z)x+b(z)y) + λ∫S(a(z)²+b(z)²).
```

右侧依次用 ∫D′max(q,0)、λB、A 的四个已绑定原始平衡矩以及 λ·mass(A)·max(a²+b²) 给出上界，第三项按等式保留符号。第一项由内接多面体精确十矩和夹层补项界定。对夹层上的 q 使用上界 1−0.9999²，其内切半径验证采用精确有理数。

所以在**四项精确平衡、固定设计域、固定轴惯量至少 90%** 的所有可测材料子集上，减重最多 **26.538730%**。结合可实现的盒修正下界，不限制质心高度时距该上界至多 0.01525 个百分点，额外要求质心不上升时至多 0.02803 个百分点。当前上界未施加打印和拓扑限制，仍适用于这些条件下的可行设计。

### 为什么这一矩约束问题存在单二次曲面最优解

将去除材料的指示函数放宽为可测密度 0≤f≤1。约束是四个矩等式和一个惯量不等式。质心不上升也可写成线性不等式 ∫removed(z−H_A)≥0。有限矩映射下的可达集紧且凸。证书中的八个高度可动的盒子使四个等式目标在可达集投影内具有开邻域（四列满秩，全部盒高严格位于上下限之间），同时锥面修正设计对两个不等式均有严格余量。因此在目标右端附近可行，最大去除体积的凹值函数在该点有超梯度，存在有限拉格朗日乘子。最优密度逐点最大化一个二次多项式乘 f，其多项式形为

```
1 − λ(x²+y²) − b₁x − b₂y − b₃xz − b₄yz + γ(z−H_A).
```

该式在任何乘子下都不可能恒等为零，因为 z 项先迫使 γ=0，余下常数为 1。非零多项式的零集体积为零，故最优密度几乎处处为其正侧的指示函数，在 D′ 上是单一二次分类。任何严格平衡并保持 90% 轴向惯量的候选，其质心处的横向惯量块均受完整 A 在 (0,0,H_A) 的横向惯量块支配（平行轴公式与非负积分）；证书给出指定轴惯量高于横向最大惯量的统一下界 0.08552。此存在性结论只覆盖列出的矩约束。最优曲面的精确系数、连接拓扑、壁厚和打印可行性尚待证明。圆柱和锥面的冻结系数是实际测试的候选参数。
