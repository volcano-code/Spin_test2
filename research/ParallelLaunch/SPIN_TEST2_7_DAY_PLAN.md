## 论文主线

在 Spin-It 的固定外形、指定转轴、保护接触点和单材料挖空任务上，用 Spin-It Faster 的二次曲面与 Newton 方法建立同题数值基线。研发基于 PINO 的三维质量矩算子，预测二次曲面与可挖域相交后得到的十矩及其对曲面参数的导数，减少昂贵的几何求值。由数值求解器校正候选并从最终整件独立复算。在预登记的旋转性能与制造约束下最小化保留材料质量，并比较同精度总耗时与同预算可行质量。五原型记录原始、重建或新设计域的身份。M32 用作首个实验载体，其结果单列为工程探索。

分开登记两种算法比较。相同原问题上比较 2014 体素路线、完整数值 Faster 和加入 PINO 的 Faster；在相同轻量化问题上让数值与学习版本都显式求解质量目标及惯量不等式。固定单密度时质量正比于保留材料体积。主阈值取初始整件轴向惯量的 90%，另验收质心、惯量对齐、按对象登记的稳定要求和连通性。学习加速的证据须包含精算回退和最终验证；质量效果按相同旋转性能比较。[Spin-It 原论文](https://igl.ethz.ch/projects/spin-it/SpinItPaper.pdf) · [Spin-It Faster 原论文](https://research-explorer.ista.ac.at/download/17203/17204/sif-final.pdf)

## 本周交付与起点

1. **建立可供学习方法比较的数值基线。** 在单密度、固定外形、固定轴、固定尖端和固定壳的 Noodles M32 上跑通原始 Spin-It Faster 目标。从保存后的最终整件网格独立重算十矩、原目标、质心位置和两项惯量对齐等式。M32 是新增工程案例，五个原型复现另行计数。
2. **检验物理学习对求解成本的影响。** 复现现有 W6，在已放行的真实评估输入上比较 A 全数值、B 局部数值、C 普通学习、D 加入物理信息的学习器。同精度比较在线总耗时，同预算比较合格解和目标值。保存结果允许无改善。
3. **建立受约束的最小质量任务，并争取首个轻量化结果。** 用登记的完整初始实体绕指定轴的惯量作分母，求小质量可行解。记录质量、减重率、轴向惯量比、原轴平衡、连通性和壁厚。独立验收后报告当前得到的最好可行质量；全局最优需要另证。

M32 在原 Noodles V7 的外形和尖端下将可挖包络按 9/10 线性内缩。94 个源部件及 1,280 个支撑平面已有核验，可挖域具正体积，连续几何的壁厚下界约 1.04910 mm。原生请求、求值域网格及四项平衡条件的共同可行性仍待验证。冻结 Heart 和 Teapot 已有原轴不可行证书，可复用作拒绝和导数回归。初始计数为严格收敛整件 0/1、五原型 0/5、真实训练标签 0、真实同预算 C/D 完整对照 0 组。[M32 几何证书](https://github.com/volcano-code/Spin_test2/blob/edb09f88f723935a030cfa4a5e28f411bfe8e720/research/NeuralMoments/teacher/M32_NOODLES_INSET_WALL.json) · [W0–W6 起点](SPIN_TEST2_W0_W6_STATUS.md)

## 同题输入与比较办法

五件原型按对象计数，同一对象的不同目标或姿态另作子案例。现有重建文件能用于可复算的工程比较。每个三方实验先固定同一份外形、可挖域、固定壳、转轴、支点、密度、长度单位和目标配置。体素法和二次曲面法使用该输入的各自表示，并分别记录离散误差。只有相同输入、目标和独立物理验收均有证据的运行才进入配对表。M32 单列为验证求解器的工程案例。

| 原型 | 仓库的重建案例 ID | 需核实的配对条件 |
|---|---|---|
| Ellipsoid | `ellipsoid-top` | 尺寸、轴、支点和离散分辨率 |
| 2014 Heart | `heart-top` | 2014 输入身份；另外登记 H8 工程案例 |
| Teapot | `teapot-inertia`、`teapot-lowering`、`teapot-mass-reduction` | 同一对象的三种目标分别评分 |
| Elephant | `elephant-accessibility` | 最终姿态、接触角色及手工切割条件 |
| Armadillo | `armadillo-hand`、`armadillo-shell` | 手支撑和壳支撑分别评分，对象计一次 |

以上八行子案例对应五件对象，已核对清单内八项输入摘要。清单标注 author_exact=false。现有 2014 重建 Ellipsoid 的八叉树深度为 4、历史容差为 0.005；清单记录的论文设置为深度 9、容差 10⁻⁶。三方同台比较要从各自最终实体复测，并做分辨率收敛检查。复用原有 2014 目标适配器，记录目标选择器、权重和坐标变换。历史 Teapot 的质量与高度组合目标与新设的 90% 惯量最小质量任务分列。 [重建清单](../../experiments/spin_it_reproduction/spin2014/paper_cases.json) · [历史证据口径](../../experiments/spin_it_reproduction/STRICT_CORRECTION.md) · [2014 目标合同](../../python/make_it_stand/verification/spin2014_objective_contract.py)

- **同精度测速度。** 每组起点、硬件、线程数和重复次数在求解前登记。三种方法按同一外形、制造约束、独立复算物理容差及事前设定的目标质量界验收。Faster 内部另按原求解器终止条件验收。首次新几何、同几何后续查询及相邻解热启动分别计时，完整数值基线可使用相同的缓存和热启动。列出成功率、全体耗时、精确调用和失败样本；报告离线训练/预处理成本及摊销所需查询数。
- **同预算测质量。** 先登记同硬件的总墙钟截止点、原生精校调用上限、随机种子、训练/适配预算及失败处理。各方法提交截止前质量最低且通过独立验收的整件，并报告质量比、惯量比和约束误差。无合格解也入表。具体秒数、调用数和数值目标容差须在该输入分割认证、量纲校验后、正式成对运行前固定。
- **先验收轻量化判据。** W0 提供有固定壁和端盖的解析圆柱，覆盖惯量约束活跃、松弛及偏轴不可平衡三种情形。运行 `python -m research.NeuralMoments.contracts.mass90_cylinder_reference` 可查看确定的参考值；可行质量和对偶下界相等。该回归独立于 M32 的物理结论。
- **实物证据。** 有最终制造文件后，为代表性原型配对称重，并在同材料、同尖端/接触面及起转条件下重复测量摆动或稳定旋转表现。数值和实测分栏登记。

## 验收口径

- **数值案例。** 本周 Faster 基线沿用已登记的严格判据，包括原生返回 CONVERGED、原方程残差 ≤ 10⁻¹²、物理相对残差 ≤ 10⁻⁶、乘子 μ > 0。W0 用最终整件的有向网格复核十矩、目标、四项物理等式、外壳、接触和连通性。核对坐标系、原点和量纲。最终点和最后接受点分别保留身份。
- **成本。** 同起点或同组起点、相同停止与回退规则、相同硬件。A/B/C/D 记录预处理、推理、Cherchi 精确调用、校正、回退、失败以及总墙钟时间。训练时间单列。预登记公平比较的总预算及重复次数；先看是否通过物理验收，再计算同精度速度比。额外的神经初值和矩/J 替代分别计时与消融。
- **轻量化。** 在指定的同一固定轴上计算 I_final/I_full ≥ 0.90，并复核单一材料、平衡、受保护面和单连通要求。M32 的 0.90 线性内缩与惯量参考分别登记。输出质量变化、当前最好可行解及优化状态。80%/95%/100% 扫描、五个原型全量重跑和额外神经骨干列入随后阶段。
- **资源和范围。** W2 享有高内存原生任务的优先权；先跑已验证的云端 CPU 路径。只有在必须测高分辨率 GPU 性能时使用本地 5090。W6 本周聚焦表示、导数和精确校正，fVDB、GeoTransolver、DensiCrafter 保留于候选目录。
